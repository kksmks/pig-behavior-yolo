# 作者信息填空模板（投稿前必填）

> 用途：v5 主稿标题页 `[Authors / affiliations to be filled]`、声明节 Funding / Author Contributions 占位、
> JRTIP 投稿系统作者信息页、作者 bio（计入 12 页，约 0.2 页）——四处共用这一份素材。
> 填好后把相应文本发给我，我替换进 docx 并重建排版；投稿系统的在线表单照着抄即可。

---

## 1. 作者行（Title page）

格式：`名 姓^1, 名 姓^2`（名字拼音，姓全大写或首字母大写均可，Springer 习惯 Given-name Surname）
示例：`Zhang San^1, Si Li^2` —— 占位行将被替换为：

```
[名 姓]^1, [导师姓名]^2,* 
```
（^1 学生单位，^2 导师单位，* 通讯作者标记在导师头上）

## 2. 单位（Affiliations）

中英文单位名的英文写法，精确到学院：
```
1. College of [学院英文名], [大学英文名], [城市 邮编], China
2. College of [学院英文名], [大学英文名], [城市 邮编], China
```
通讯邮箱：`*Corresponding author: [导师邮箱]`
ORCID：导师一般已有；学生没有可不填（或去 https://orcid.org 免费注册，2 分钟）

## 3. Author Contributions（CRediT 标准角色，选适用项）

Springer 要求按 CRediT 分类写。本科生一作 + 导师通讯的典型写法：

```
[姓名]: Conceptualization, Methodology, Software, Validation, Formal analysis, Investigation,
Data curation, Writing—original draft, Visualization. 
[导师姓名]: Supervision, Writing—review and editing, Project administration.
```
（若导师还出了主意/改了实验设计，加 Conceptualization 共享："Conceptualization: [姓名], [导师姓名]"）

## 4. Funding（二选一）

无资助（本科生常见，完全合规）：
```
Funding: The authors received no specific funding for this work.
```
有资助（导师愿意挂项目时，可能换来版面费报销）：
```
Funding: This work was supported by [基金名] (grant No. [编号]).
```

## 5. 作者 bio（JRTIP 硬性要求，每人 50–80 词，附照片可选）

模板：
```
[Name] is an undergraduate student at the College of [学院], [大学], China. 
His/Her research interests include computer vision, edge computing, and precision 
livestock farming. This is his/her first peer-reviewed publication.

[导师姓名] is a [Professor/Associate Professor/Lecturer] at the College of [学院], 
[大学], China. He/She received the Ph.D. degree from [学校] in [年份]. His/Her 
research interests include [方向]. He/She has authored or co-authored [约数] 
peer-reviewed publications.
```
