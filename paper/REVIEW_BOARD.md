# 模拟审稿团（Review Board）

## 机制

- **召集时机**：① 每个重大交付物（实验体系、分析包、部署验证）② 论文每章完稿 ③ 投稿前终审
- **流程**：助手分饰三角，各自独立出意见 → 汇总为评审报告（本文件追加）→ 逐条定"对策/状态"
- **目标**：让真实审稿人收到的版本已经过三轮内部炮火

## 审查维度 v2（2026-08-04 扩维，原 4 维 → 10 维）

| # | 维度 | 检查要点 |
|---|---|---|
| D1 | 统计一致性 | 单次值 vs 均值标注、val/test 归属、误差棒 |
| D2 | 实验完整性 | 消融阶梯、对照组同协议、阴性对照 |
| D3 | 边界诚实 | 弱类/泛化/FLOPs/INT8 等限制如实声明 |
| D4 | 创新点厚度 | 模块数 + 方法论贡献是否撑得起目标刊 |
| D5 | 引用完整性与格式 | 每个事实性声明有引、无二手转引错、JRTIP 数字制 [n]、DOI 仅写已核实者 |
| D6 | 图表规范 | 图表全部按序在正文引用、Springer 图题式（Fig. N 无点后缀无尾句号）、灰度可辨（纹理/线型不止颜色）、图内无标题、图内 sans-serif |

| D9 | 可复现性 | 超参全列、种子数、版本号、代码/数据开放声明 |
| D10 | 期刊条款契合 | JRTIP cover letter 必须论述 real-time 问题（"只报速度不算讨论实时性"）、作者 bio 要求 |
